# ⚡ Neon Weather Board - Live Weather Intelligence

WeatherX Pro is a modern weather forecasting web application built using **HTML, CSS, and JavaScript**. It allows users to search for any city worldwide and instantly view real-time weather information through a clean and responsive interface.

---

# 🌍 Overview

WeatherX Pro provides accurate weather insights with a sleek user experience designed for both desktop and mobile users. The project demonstrates API integration, dynamic content rendering, and responsive web design principles.

---

# ✨ Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature updates
* ☁️ Current weather conditions
* 💨 Wind speed information
* 💧 Humidity monitoring
* 🌎 Global city support
* 📱 Responsive design
* ⚡ Fast and lightweight performance

---

# 🖼️ Application Sections

### 🏠 Hero Section

Modern landing page introducing the platform and its capabilities.

### 🔎 Weather Search

Users can enter any city name and retrieve live weather data instantly.

### 📊 Results Panel

Displays detailed weather information in an organized layout.

### 📱 Responsive Interface

Optimized for desktops, tablets, and smartphones.

# 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/iqbolshoh/neon-weather-board
```

### 2. Open the Project

Simply open the `index.html` file in your browser.

### 3. Search Weather

* Enter a city name
* Click the Search button
* View live weather data instantly
